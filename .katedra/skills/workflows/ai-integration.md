# SKILL: AI Integration & Content Consumption (Katedra Frontend)

## 1. CONTEXT OF ACTIVATION (C_σ)
- **Trigger:** Displaying AI-generated content (theory, exercises, evaluations, slides), handling loading/error states during content generation, or managing asynchronous content loading from the backend.
- **Exclusion:** Does NOT handle direct LLM API calls (handled in Python backend), prompt engineering (handled in Python backend), or database operations (handled by Spring backend).
- **Important:** AI content is generated by backend services (Spring + Python). Frontend only consumes and displays.

## 2. STRICT ARCHITECTURAL RULES (T_σ)
- **Content Source:** All AI-generated educational content comes from backend REST APIs (Spring Backend uses Spring AI ChatClient).
  - Backend Provider: **OpenAI (GPT-4, GPT-4-turbo, GPT-4o)** with structured JSON output via Spring AI
  - Spring AI abstracts provider logic (supports Anthropic, Azure OpenAI, other providers with config-only changes)
- **Frontend Responsibilities:**
  - Consume `/temarios/{id}/contenido` endpoint to fetch generated theory, exercises, evaluations, slides
  - Handle loading/async states while backend generates content (show spinners, disable buttons, set timeouts ~30-60s)
  - Display structured JSON responses (theory as markdown, exercises as formatted lists, evaluations as quizzes)
  - Handle errors gracefully (network timeouts, 500 errors from backend)
- **No Direct AI Calls:** Frontend MUST NOT call OpenAI, Anthropic, or any LLM API directly. All LLM interactions happen in Spring Backend (via Spring AI ChatClient).
- **Async Handling:** Content generation is async/non-blocking on backend (@Async, CompletableFuture). Frontend shows loading state and handles response when ready.

## 3. STANDARD OPERATING PROCEDURE (π_σ)
1. **Content Fetching:** Call Spring backend endpoint `/temarios/{id}/contenido` to retrieve generated content.
2. **Response Structure:** Expect JSON with fields: `teoria` (string), `ejercicios` (string), `evaluacion` (array of questions), `diapositivas` (array of slides).
3. **Loading State:** Show loading spinner while backend generates content. Set reasonable timeout (30-60 seconds).
4. **Display & Rendering:**
   - **Teoria:** Render as markdown (supports headers, lists, code blocks, LaTeX formulas)
   - **Ejercicios:** Display as formatted text with syntax highlighting
   - **Evaluacion:** Render as interactive quiz with multiple choice questions
   - **Diapositivas:** Display as slide presentation or card deck
5. **Error Handling:** If backend returns error, show user-friendly message ("Content generation failed. Please try again.") and log error details.

## 4. COMPACT RECIPE (FEW-SHOT)
Input: "Display AI-generated quiz content from backend while content is being generated"
Output Expected:
```tsx
// 1. Hook to fetch content from backend
const useTemarioContent = (temarioId: string) => {
  const [content, setContent] = useState<ContenidoTemarioDTO | null>(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    const fetchContent = async () => {
      try {
        const response = await fetch(`/api/temarios/${temarioId}/contenido`);
        if (!response.ok) throw new Error("Failed to fetch content");
        const data = await response.json();
        setContent(data);
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    };

    fetchContent();
  }, [temarioId]);

  return { content, loading, error };
};

// 2. Component to display generated quiz
export const TemarioViewer: React.FC<{ temarioId: string }> = ({ temarioId }) => {
  const { content, loading, error } = useTemarioContent(temarioId);

  if (loading) return <LoadingSpinner message="Generating educational content..." />;
  if (error) return <ErrorBanner message={`Error: ${error}`} />;
  if (!content) return <div>No content available</div>;

  return (
    <div className="temario-viewer">
      <section className="teoria">
        <h2>Theory</h2>
        <Markdown>{content.teoria}</Markdown>
      </section>

      <section className="ejercicios">
        <h2>Exercises</h2>
        <PreformattedText>{content.ejercicios}</PreformattedText>
      </section>

      <section className="evaluacion">
        <h2>Quiz</h2>
        <QuizComponent questions={content.evaluacion} />
      </section>

      <section className="diapositivas">
        <h2>Slides</h2>
        <SlidePresentation slides={content.diapositivas} />
      </section>
    </div>
  );
};
```

**Key Points:**
- Frontend only consumes backend APIs
- Loading state handles async generation
- No direct LLM calls in React component
- Error handling graceful and user-friendly
